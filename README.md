## Data source

The primary analyses use the original UCI Echocardiogram dataset comprising 132 source records.

The dataset is used for post-myocardial-infarction survival analysis, with survival time measured in months and death treated as the event. Synthetic observations generated in this repository are used only for methodological augmentation experiments and are not treated as independent patients or external validation data.

Original data source: [UCI Machine Learning Repository – Echocardiogram dataset](https://archive.ics.uci.edu/)
