# Scientific Reports major-revision reproducibility package

## Canonical source data
`uci_echocardiogram_reconstructed_132.csv` is the correctly parsed 132-record UCI Echocardiogram dataset used for the revision audit. The survival endpoint is `survival` in months after myocardial infarction; `event=1` denotes death and `event=0` denotes censoring/still alive.

## Main entry point
Run:

```bash
python Scientific_Reports_Reanalysis_Master_v2.py --data uci_echocardiogram_reconstructed_132.csv --outdir rerun_outputs
```

This runs the corrected real-data core analysis, nested FP-Cox validation, and synthetic-data fidelity/utility experiment.

## Final standard-package confirmation
Before manuscript submission, install scikit-survival and run:

```bash
pip install scikit-survival
python Scientific_Reports_Reanalysis_Master_v2.py --data uci_echocardiogram_reconstructed_132.csv --outdir rerun_outputs --standard-confirmation
```

The confirmation uses `sksurv.metrics.concordance_index_censored`, `brier_score`, and `integrated_brier_score` on identical repeated cross-validation splits. It evaluates Cox PH, RSF, nested FP-Cox, synthetic-only training, and real-plus-synthetic training on held-out real observations.

## Synthetic-data design
Synthetic records are generated by a smoothed multivariate bootstrap fitted within each real training fold. No invented ejection fraction, blood pressure, smoking, cholesterol, or diabetes variables are used. Synthetic observations are never treated as independent patients or external validation data.

## Files to retain for reviewer reproducibility
The code scripts, reconstructed source CSV, locked-results ledger, generated CSV/PNG outputs, and package requirements should be deposited together in the final GitHub/Zenodo release. Do not use the earlier corrupted 100,000-row file in the revised analysis.
